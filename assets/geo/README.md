# Contorno de Tlaxcala

La geometría procede del [servicio del Catálogo Único de Claves de Áreas Geoestadísticas Estatales del INEGI](https://gaia.inegi.org.mx/wscatgeo/v2/geo/mgee/29), para la clave 29. La respuesta declara como fuente el Marco Geoestadístico de diciembre de 2025.

`tlaxcala-inegi.geojson` conserva los datos descargados. `tlaxcala-inegi.svg` se genera mediante `node scripts/generar-silueta.mjs`: proyecta las coordenadas para visualizar el contorno, sin simplificarlo ni reemplazarlo por una interpretación generada. Como cualquier visualización de datos geográficos, está sujeta a la proyección, a la escala y a la actualización del conjunto de datos.
