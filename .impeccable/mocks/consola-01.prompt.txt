Use case: ui-mockup. Render a complete desktop interactive personal website for Nery as a quiet, clean command-line inspired exploration screen, edge to edge, landscape 1536x1024, no physical monitor or computer window. Use plenty of calm empty space. Make the destination nodes readable and visibly interactive: “Buenavista”, “Historia / Wikimedia”, “Proyectos”, “Conocimientos”, “Trayectoria”, “Contacto”. Direct, functional screen controls in Poppins: “Mapa”, “Índice”, “Ayuda”, and a small footer “Selecciona una parada”. Use monospace only for the aligned map characters; Poppins for ordinary interface labels and dialogue. The screen should feel like the output of a modern text interface, highly intentional and elegant, with clear hierarchy and practical readable type. Muted warm ivory and a restrained amber accent, no neon. The distinctive visual move is the exact map drawn as text graphics. No photographic imagery, no rich illustration, no paper texture, no elaborate borders, no fantasy scenery, no gradients, no glow, no fake terminal log, no splash screen, no dashboard cards. It must read as an interactive map rather than a code editor.
